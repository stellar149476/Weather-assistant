# 天气出行小助手 · CYBER NEON

> 一个纯前端、零依赖、双击即开的天气网页：输入城市，不只看天气，还直接告诉你「今天怎么穿、几点出门合适、要不要带伞、去哪玩靠谱」。

- **运行方式**：双击 `index.html`（或本地起个静态服务器）
- **技术栈**：原生 HTML / CSS / JavaScript（无框架、无构建、无 API Key）
- **形态**：单文件页面（`index.html` 已内联全部样式、脚本与壁纸）
- **作者**：Stellar149476

---

## 一、项目简介

常见天气页面止步于「多少度、下不下雨」。本项目在气象数据之上加了一层**规则引擎**，把原始数据换算成可直接执行的出行结论：

- 生活指数 6 项（紫外线 / 运动 / 穿衣 / 洗车 / 晾晒 / 感冒）
- 天气预警（高温、暴雨、大风、雾霾，按阈值分级触发）
- 出行建议、活动推荐
- **出行智能规划**：选择「出行目的 + 出行时段」，自动生成通用装备与专属装备清单
- 城市天气对比（两城并排看差异）

视觉上提供两套完全独立的主题：深色**赛博朋克霓虹**（默认）与浅色**樱花二次元**，一键切换并记忆偏好。

## 二、快速开始

```bash
# 方式一：直接双击 index.html（无需任何环境）

# 方式二：本地服务器（推荐，定位功能才能用）
cd weather-cyber
python -m http.server 8000
# 浏览器打开 http://localhost:8000/index.html
```

**注意三件事**

1. **需联网**：天气数据来自公开 API，离线打不开数据（页面骨架与动效仍正常）。
2. **音乐文件**：`daylight-seredris.mp3` 必须与 `index.html` 放在同一目录，否则右下角音乐按钮会提示「未找到音乐文件」。
3. **浏览器策略**：带声音的音频不允许「无交互自动播放」。页面会先尝试自动播放，被拦截时提示「点击页面任意处开始播放」，随后点击 / 按键 / 触摸 / 滚动任意一下即自动开始，无需专门去点按钮。

## 四、技术实现要点

**1. 零依赖、单文件交付**
不使用任何框架、CSS 预处理器或打包工具，全部手写原生 HTML/CSS/JS（ES2020）。`index.html` 为内联单文件版本（约 670KB，其中壁纸以 base64 内嵌），便于双击打开与单独分享。

**2. 代码分层**
```
配置区（API 地址、默认城市、WMO 天气代码表）
  ↓
数据层（请求 + 归一化 normalizing）
  ↓
数据源适配（MET Norway / Open-Meteo → 统一内部结构）
  ↓
规则引擎（生活指数 / 预警 / 建议 / 装备）
  ↓
渲染层（DOM 拼装、SVG 天气图标）
  ↓
交互层（搜索、对比、主题、动效、悬浮控件）
```

**3. 双数据源的「统一结构」设计**
两家 API 字段与颗粒度差异很大（MET Norway 无日聚合、无紫外线、无空气质量）。适配层把两者归一化成同一结构后再交给上层，因此**渲染与规则引擎完全不关心数据来自哪家**。缺失项显式保留 `null`，界面显示「该数据源不提供」而不是错误地当成 `0`。

**4. 规则引擎而非写死文案**
生活指数、预警等级、出行建议、装备清单全部由实时数值 + 阈值区间推导（例如体感温度 → 穿衣建议；24 小时累计降水 + 风力 → 洗车指数；昼夜温差 + 湿度 → 感冒指数），换城市换天气结论随之变化。

**5. 主题与性能**
- 主题：`:root` 定义全套语义化 CSS 变量，`html[data-theme="light"]` 整体覆盖；`<head>` 内联脚本在首帧前读 localStorage 定主题，杜绝白闪。
- 动效：`requestAnimationFrame` + Canvas 双层渲染，按 `devicePixelRatio` 适配高清屏；尊重系统 `prefers-reduced-motion` 与省流量模式，自动关闭特效。
- 交互：滚动监听用 rAF 节流，搜索用防抖，首次加载显示骨架屏。

**6. 可访问性**
按钮均带 `aria-label` / `aria-pressed`，图标 SVG 标记 `aria-hidden`，键盘焦点有可见描边（`focus-visible`），全站可用键盘操作。

**7. 本地存储一览**
| Key | 用途 |
| --- | --- |
| `wf.city.v3` | 上次查看的城市 |
| `wf.theme.v1` | 深浅主题偏好 |
| `wf.src.v2` | 数据源偏好 |
| `wf.fx.mode.v1` | 渲染方式偏好 |
| 搜索历史 | 最近 5 个城市 |

## 八、已知限制

- 需联网获取数据；`file://` 协议下浏览器禁用定位，需改用本地服务器。
- 单文件分享时需连同 `daylight-seredris.mp3` 一起提供，否则音乐不可用（可选方案：将音频 base64 内嵌，文件体积会增至约 9MB）。
- 「Norway 源」不提供空气质量与紫外线指数，界面会明确标注「该数据源不提供」，切换到「Meteo 源」可获取。
- 生活指数、预警、出行建议均为**基于气象数据的规则推算**，非气象部门官方发布，仅供参考。

## 九、三分钟验收路径

1. 双击 `index.html` → 首屏显示南昌实时天气（或上次城市）；观察背景粒子与深色霓虹风格。
2. 搜索框输入「杭州」回车 → 数据切换；点「对比」再输入另一城市 → 出现并排对比卡；点「退出对比」返回。
3. 点右上角图标切浅色主题 → 整体变为樱花配色，刷新后仍保持。
4. 滚动页面到底部 → 右下角出现进度环按钮，点击回顶；左下角点音乐按钮 → 图标出现斜杠、提示「音乐已暂停」，再点恢复。
5. 在「出行智能规划」里切换出行目的与时段 → 下方装备清单与提示同步变化。
